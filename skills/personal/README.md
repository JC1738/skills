# Personal

Skills tied to my own setup, not promoted in the plugin — but written to be configurable, so others
can point them at their own tools.

The four AppFlowy-backed domain-context skills (`load-domain-context`, `domain-context-mcp`,
`grill-with-context`, `improve-arch-with-context`) are configurable for anyone — see **[SETUP.md](./SETUP.md)**
to point them at your own AppFlowy workspace.

- **[edit-article](./edit-article/SKILL.md)** — Edit and improve articles by restructuring sections, improving clarity, and tightening prose.
- **[obsidian-vault](./obsidian-vault/SKILL.md)** — Search, create, and manage notes in an Obsidian vault with wikilinks and index notes.
- **[domain-context-mcp](./domain-context-mcp/SKILL.md)** — Active domain modeling when the glossary and decisions live in AppFlowy (and work in Plane) instead of markdown files.
- **[load-domain-context](./load-domain-context/SKILL.md)** — Read-only: load the current repo's domain glossary live from AppFlowy (registry-resolved). Auto-run by a SessionStart hook on Claude Code; invoke directly in Cowork/web.
- **[grill-with-context](./grill-with-context/SKILL.md)** — Relentless interview to sharpen a plan/design for a repo whose glossary and decisions live in AppFlowy/Plane.
- **[improve-arch-with-context](./improve-arch-with-context/SKILL.md)** — Scan a codebase for deepening opportunities and grill through one, sourcing the domain model live from AppFlowy instead of markdown.
